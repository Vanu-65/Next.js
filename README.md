# Next.js — SVB

Мой сайт SVB — Создаём вместе будущее!

Лендинг на [Next.js](https://nextjs.org) (App Router, TypeScript, Tailwind CSS).

## Локальный запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере.

## Сборка

```bash
npm run build
npm start
```
